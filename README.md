# 💳 Alke Wallet

Proyecto desarrollado para el módulo:
Fundamentos del Desarrollo Front-End.

## 📌 Descripción

Alke Wallet es una billetera digital responsive desarrollada con:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- jQuery

La aplicación permite:

✅ Inicio de sesión  
✅ Visualización de saldo  
✅ Depósitos  
✅ Transferencias  
✅ Agenda de contactos  
✅ Historial de movimientos  
✅ Filtros dinámicos  
✅ Interfaz responsive  

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES6
- jQuery
- Bootstrap 5
- LocalStorage
